# Bài tập 1: Tính tổng và trung bình cộng hai số (C++)
Chương trình C++ nhập hai số thực a, b từ bàn phím, tính tổng và trung bình cộng của a và b
## Mô tả bài toán
- **Input:** Hai số thực a và b.
- **Output:** Tổng của a và b, giá trị trung bình cộng của a và b
## Cách biên dịch và chạy
- **Yêu cầu:** Trình biên dịch C++ (g++)
- **Lệnh biên dịch và chạy:**
  ```bash
  g++ main.cpp -o main
  ./main
