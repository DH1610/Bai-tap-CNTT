# Bài tập 1: Tính tổng và trung bình cộng hai số (C++)
Chương trình C++ nhập hai số thực `a`, `b` từ bàn phím, tính tổng và trung bình cộng rồi in kết quả ra màn hình.
## Mô tả bài toán
- **Input:** Hai số thực `a` và `b`.
- **Output:** Tổng của `a` và `b`, cùng giá trị trung bình cộng.
## Cách biên dịch và chạy
- **Yêu cầu:** Trình biên dịch C++ (`g++`).
- **Lệnh biên dịch và chạy:**
  ```bash
  g++ main.cpp -o main
  ./main
